# Client Sales Data Analysis

An Excel project analyzing client order data using Pivot Tables and charts to break down sales performance by region and product category.

## What's Inside

- **Orders** — Raw order-level data: Order ID, Date, Product Code, Product Name, Region, Sales Rep, Quantity, Unit Price, Category, Standard Cost, and Total Sales.
- **Product Reference** — A lookup table mapping each Product Code to its Category and Standard Cost, used to enrich the Orders sheet.
- **Total Sales** — Two Pivot Tables summarizing total sales:
  - By **Region** (North, South, East, West)
  - By **Category** (Accessories, Displays, Electronics, Office)
  
  Each Pivot Table is paired with a chart for quick visual comparison.

## Key Insight

The **North region** and **Accessories category** drive the largest share of total sales, while Displays contribute the least — useful for spotting where sales focus (or restocking priority) should go.

## Skills Demonstrated

- Pivot Tables & Pivot Charts
- Lookup tables (VLOOKUP / INDEX-MATCH style referencing between sheets)
- Data organization across multiple related sheets
- Sales performance analysis by dimension (region, category)
