# Excel Data Analysis Projects

A collection of Excel projects demonstrating data cleaning, Pivot Tables, formulas, and dashboard-style analysis on realistic business datasets.

## Projects

| Project | Description | Key Skills |
|---|---|---|
| [Client Sales Data](./Client-Sales-Data) | Sales performance broken down by region and product category using Pivot Tables and charts | Pivot Tables, Pivot Charts, Lookup Tables |
| [Customer Feedback Analysis](./Customer-Feedback-Analysis) | Cleaning messy customer feedback data — split names, missing values, added status tracking | Data Cleaning, Handling Missing Values |
| [Inventory Analysis](./Inventory-Analysis) | Inventory cost analysis by warehouse city and product category | Pivot Tables, Cost Aggregation |
| [Q1 Regional Sales Report](./Q1-Regional-Sales-Report) | Monthly regional sales rolled into a live summary using SUMIFS formulas | SUMIFS, Cross-Sheet Formulas |

Each project folder contains the Excel workbook and its own README with details on the dataset, approach, and key insights.

## Tools Used

Microsoft Excel — Pivot Tables, Pivot Charts, SUMIFS, VLOOKUP/INDEX-MATCH style lookups, data cleaning
